# Switch UI 1.005.000

- Updated for official ProsperoEden 1.005.000.
- Adds global and per-game Speed limit: 100%, 150%, 200%, 300% and Unlimited, with a Follows Settings option per game.
- Separates Mods and Cheats, each with its own master switch. Cheat-only entries are hidden from Mods.
- Adds Update notices under System. About still shows an available ProsperoEden update when startup notices are disabled.
- Supports game-local reshade presets alongside shared post-processing presets.
- Retains the previous performance work, animations, navigation memory, saved preferences, artwork, loading screen and sounds.

**Minimum ProsperoEden version: 1.005.000.**

The official host does not expose frame generation method selection to Lua. The Video menu retains the guided built-in-launcher shortcut for choosing MihawkGen or Lossless Scaling. The frame generation toggle, target and multiplier use that saved method. This release contains no host changes.
